# Robinhood Chain Buybot Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** A self-serve Telegram bot that posts a card in a token's community group on every buy of that token on Robinhood Chain, sourced from the Pons.family V2 bonding curve and all Uniswap V2/V3/V4 pools.

**Architecture:** One Node process: a `getUpdates` loop handles `/add`, `/settings`, etc. and writes per-group settings to SQLite; a `Watcher` keeps one WebSocket `eth_subscribe("logs")` filtered to the tracked pools (with `eth_getLogs` backfill and a polling fallback); pure decoders normalise V2/V3/V4/Pons logs into a `Trade`; an enricher adds ETH/USD, market cap and holder status; a rate-limited `Poster` sends the card (with the group's uploaded GIF) to every group tracking that token.

**Tech Stack:** TypeScript (ESM) on Node ≥ 20 via `tsx`, `better-sqlite3` (WAL), `ethers` v6 (ABI coder + keccak only), `ws`, `dotenv`, `vitest`. Spec: `docs/superpowers/specs/2026-08-25-buybot-design.md`. Research: `docs/superpowers/research/2026-08-25-buybot-research.md`.

## Global Constraints

- Repo: `d:\robinhood-buybot` (GitHub `blockfile/robinhood-buybot`, branch `main`). All paths below are relative to it.
- Node ≥ 20, `"type": "module"`, TypeScript `strict: true`, `noEmit`; run with `tsx`; tests with `vitest run`; typecheck with `tsc --noEmit`. Both must pass at the end of every task.
- Chain ID `4663`. Native gas token ETH (18 decimals). ~100 ms blocks. `eth_getLogs` range ≤ 10,000 blocks per call.
- Every network client takes an injected `fetchFn: typeof fetch` (tests never touch the network). Every timestamp-taking function takes `now` as a parameter.

- Only ETH/WETH-quoted pools are tracked in v1 (Pons pools quoted in SPCX or other tokens are skipped — see Follow-ups).
- Telegram: HTML parse mode; media captions ≤ 1,024 chars; per-chat send interval 3 s; global 25 msg/s.

```ts
import 'dotenv/config';
import { readFileSync } from 'node:fs';
import type { AppConfig, Secrets } from './types';

export function loadConfig(path = 'config.json'): AppConfig {
  const cfg = JSON.parse(readFileSync(path, 'utf8')) as AppConfig;

  const numeric: Array<[string, unknown]> = [
    ['defaults.stepUsd', cfg.defaults?.stepUsd],
    ['defaults.minBuyUsd', cfg.defaults?.minBuyUsd],
    ['watcher.backfillBlocks', cfg.watcher?.backfillBlocks],
    ['watcher.staleSeconds', cfg.watcher?.staleSeconds],
    ['watcher.pollFallbackAfterSeconds', cfg.watcher?.pollFallbackAfterSeconds],
    ['discovery.refreshMinutes', cfg.discovery?.refreshMinutes],
    ['limits.maxEmojis', cfg.limits?.maxEmojis],
    ['limits.maxTokensPerGroup', cfg.limits?.maxTokensPerGroup],
  ];
  for (const [name, v] of numeric) {
    if (typeof v !== 'number' || !Number.isFinite(v)) throw new Error(`config.json missing numeric field: ${name}`);
  }
  const strings: Array<[string, unknown]> = [
    ['adLine', cfg.adLine],
    ['trendingUrl', cfg.trendingUrl],
    ['defaults.emoji', cfg.defaults?.emoji],
  ];
  for (const [name, v] of strings) {
    if (typeof v !== 'string') throw new Error(`config.json missing string field: ${name}`);
  }
  for (const key of ['pons', 'uniswap'] as const) {
    const v = cfg.buyUrls?.[key];
    if (typeof v !== 'string' || !v.includes('{token}')) {
      throw new Error(`config.json buyUrls.${key} must be a URL template containing {token}`);
    }
  }
  if (cfg.defaults.stepUsd <= 0) throw new Error('config.json defaults.stepUsd must be > 0');
  return cfg;
}

export function loadSecrets(env: Record<string, string | undefined> = process.env): Secrets {
  const missing: string[] = [];
  const get = (k: string): string => {
    const v = env[k];
    if (!v) missing.push(k);
    return v ?? '';
  };
  const secrets: Secrets = {
    botToken: get('BUYBOT_TOKEN'),
    rpcUrl: get('RH_RPC_URL'),
    wsUrl: get('RH_WS_URL'),
    dbPath: env['DB_PATH'] || 'data/buybot.sqlite',
  };
  if (missing.length) {
    throw new Error(`Missing required values in .env: ${missing.join(', ')}. Copy .env.example to .env and fill it in.`);
  }
  return secrets;
}
```

```ts
let dirReady = false;

export function log(level: LogLevel, msg: string): void {
  const line = `${new Date().toISOString()} [${level}] ${msg}`;

  try {
    if (!dirReady) { mkdirSync('logs', { recursive: true }); dirReady = true; }
```

```ts
import { AbiCoder } from 'ethers';

const coder = AbiCoder.defaultAbiCoder();

/** 64-hex-char word `i` of ABI data (with or without 0x). Throws if out of range. */
export function word(data: string, i: number): string {
  const d = data.startsWith('0x') ? data.slice(2) : data;
  const w = d.slice(64 * i, 64 * i + 64);
  if (w.length !== 64) throw new Error(`abi: word ${i} out of range (data has ${d.length / 64} words)`);
  return w;
}

export function toUint(w: string): bigint {
  return BigInt('0x' + w);
}

/** Two's-complement int256 (also correct for int128 — the ABI sign-extends to 32 bytes). */
export function toInt(w: string): bigint {
  const v = BigInt('0x' + w);
  return v >= 1n << 255n ? v - (1n << 256n) : v;
}

export function toAddress(w: string): string {
  return ('0x' + w.slice(-40)).toLowerCase();
}

export function topicAddress(topic: string): string {
  return toAddress(topic.startsWith('0x') ? topic.slice(2) : topic);
}

export function addressTopic(addr: string): string {
  return '0x' + addr.toLowerCase().replace(/^0x/, '').padStart(64, '0');
}

export function encodeCall(selector: string, types: string[] = [], values: unknown[] = []): string {
  return selector + (types.length ? coder.encode(types, values).slice(2) : '');
}

export function decodeResult(types: string[], hex: string): unknown[] {
  return Array.from(coder.decode(types, hex));
}

/** Decode an eth_call result that is either an ABI-encoded string or a legacy bytes32 symbol. */
export function decodeAbiString(hex: string | undefined): string | null {
  if (!hex || hex === '0x') return null;
  const data = hex.slice(2);
  try {
    let bytes: string;
    if (data.length > 64) {
      const offset = parseInt(data.slice(0, 64), 16) * 2;
      const len = parseInt(data.slice(offset, offset + 64), 16) * 2;
      bytes = data.slice(offset + 64, offset + 64 + len);
    } else {
      bytes = data;
    }
    let out = '';
    for (let i = 0; i < bytes.length; i += 2) {
      const c = parseInt(bytes.slice(i, i + 2), 16);
      if (!c) break;
      out += String.fromCharCode(c);
    }
    const trimmed = out.trim();
    return trimmed.length ? trimmed : null;
  } catch {
    return null;
  }
}
```

```ts
import type { LogFilter, RawLog } from './types';

export class RpcError extends Error {
  constructor(msg: string, public code?: number) {
    super(msg);
    this.name = 'RpcError';
  }
}

export type Settled = { ok: true; result: unknown } | { ok: false; error: string };
export interface RpcCall { method: string; params: unknown[] }

export function hexTag(n: number | 'latest'): string {
  return n === 'latest' ? 'latest' : '0x' + n.toString(16);
}

export function normalizeLog(l: any): RawLog {
  return {
    address: String(l.address).toLowerCase(),
    topics: ((l.topics ?? []) as string[]).map((t) => t.toLowerCase()),
    data: l.data ?? '0x',
    blockNumber: parseInt(l.blockNumber, 16),
    transactionHash: String(l.transactionHash).toLowerCase(),
    logIndex: parseInt(l.logIndex, 16),
    removed: !!l.removed,
  };
}

/** Batched JSON-RPC over HTTP. Every public method throws `RpcError` on transport or RPC failure. */
export class Rpc {
  private nextId = 1;

  constructor(private url: string, private fetchFn: typeof fetch = fetch, private timeoutMs = 15_000) {}

  async batchSettled(calls: RpcCall[]): Promise<Settled[]> {
    if (!calls.length) return [];
    const body = calls.map((c) => ({ jsonrpc: '2.0', id: this.nextId++, method: c.method, params: c.params }));
    const res = await this.fetchFn(this.url, {
      method: 'POST',
      headers: { 'content-type': 'application/json' },
      body: JSON.stringify(body),
      signal: AbortSignal.timeout(this.timeoutMs),
    });
    if (!res.ok) throw new RpcError(`rpc http ${res.status}`);
    const json = (await res.json()) as Array<{ id: number; result?: unknown; error?: { code: number; message: string } }>;
    if (!Array.isArray(json)) throw new RpcError('rpc: non-array batch response');
    const byId = new Map(json.map((r) => [r.id, r]));
    return body.map((req) => {
      const r = byId.get(req.id);
      if (!r) return { ok: false, error: `missing response for ${req.method}` };
      if (r.error) return { ok: false, error: `${req.method}: ${r.error.message} (${r.error.code})` };
      return { ok: true, result: r.result };
    });
  }

  async batch(calls: RpcCall[]): Promise<unknown[]> {
    const settled = await this.batchSettled(calls);
    return settled.map((s) => {
      if (!s.ok) throw new RpcError(`rpc ${s.error}`);
      return s.result;
    });
  }

  async one(method: string, params: unknown[]): Promise<unknown> {
    return (await this.batch([{ method, params }]))[0];
  }

  async call(to: string, data: string, blockTag: number | 'latest' = 'latest'): Promise<string> {
    return (await this.one('eth_call', [{ to, data }, hexTag(blockTag)])) as string;
  }

  async blockNumber(): Promise<number> {
    return parseInt((await this.one('eth_blockNumber', [])) as string, 16);
  }

  async getLogs(filter: LogFilter): Promise<RawLog[]> {
    const param: Record<string, unknown> = {
      topics: filter.topics,
      fromBlock: hexTag(filter.fromBlock),
      toBlock: hexTag(filter.toBlock),
    };
    if (filter.address?.length) param.address = filter.address;
    const raw = ((await this.one('eth_getLogs', [param])) as any[] | null) ?? [];
    return raw.map(normalizeLog);
  }

  async getTransactionFrom(txHash: string): Promise<string | null> {
    const tx = (await this.one('eth_getTransactionByHash', [txHash])) as { from?: string } | null;
    return tx?.from ? tx.from.toLowerCase() : null;
  }
}
```

```ts
import type { RawLog } from '../chain/types';
import type { Pool, Trade } from './types';

/** Execution price: ETH per whole token. 0 when no tokens moved. */
export function execPrice(quoteWei: bigint, tokensRaw: bigint, decimals: number): number {
  if (tokensRaw === 0n) return 0;
  return (Number(quoteWei) / 1e18) / (Number(tokensRaw) / 10 ** decimals);
}

/** Uniswap V3/V4 sqrtPriceX96 → ETH per whole token, for the token in position 0 or 1. */
export function sqrtPriceToQuotePerToken(sqrtPriceX96: bigint, tokenIs0: boolean, decimals: number): number {
  const ratio = (Number(sqrtPriceX96) / 2 ** 96) ** 2; // raw token1 per raw token0
  const rawQuotePerToken = tokenIs0 ? ratio : 1 / ratio;
  return rawQuotePerToken * 10 ** decimals / 1e18;
}

export const abs = (v: bigint): bigint => (v < 0n ? -v : v);

export function trade(log: RawLog, pool: Pool, fields: Pick<Trade, 'buy' | 'quoteIn' | 'tokensOut' | 'priceQuotePerToken' | 'recipient'>): Trade {
  return {
    token: pool.token,
    pool,
    ...fields,
    txHash: log.transactionHash,
    logIndex: log.logIndex,
    blockNumber: log.blockNumber,
  };
}
```

```ts
import { TOPIC_V2_SWAP } from '../chain/constants';
import { word, toUint, topicAddress } from '../chain/abi';
import type { RawLog } from '../chain/types';
import type { Pool, Trade } from './types';
import { execPrice, trade } from './common';

/** Swap(address indexed sender, uint amount0In, uint amount1In, uint amount0Out, uint amount1Out, address indexed to) */
export function decodeV2(log: RawLog, pool: Pool): Trade | null {
  if (log.topics[0] !== TOPIC_V2_SWAP || log.topics.length < 3) return null;
  const a0In = toUint(word(log.data, 0)), a1In = toUint(word(log.data, 1));
  const a0Out = toUint(word(log.data, 2)), a1Out = toUint(word(log.data, 3));
  const tokIn = pool.tokenIs0 ? a0In : a1In, tokOut = pool.tokenIs0 ? a0Out : a1Out;
  const qIn = pool.tokenIs0 ? a1In : a0In, qOut = pool.tokenIs0 ? a1Out : a0Out;
  let buy: boolean, quote: bigint, tokens: bigint;
  if (tokOut > 0n && qIn > 0n) { buy = true; quote = qIn; tokens = tokOut; }
  else if (tokIn > 0n && qOut > 0n) { buy = false; quote = qOut; tokens = tokIn; }
  else return null;
  return trade(log, pool, { buy, quoteIn: quote, tokensOut: tokens, priceQuotePerToken: execPrice(quote, tokens, pool.decimals), recipient: topicAddress(log.topics[2]) });
}
```

```ts
import { TOPIC_PONS_BUY, TOPIC_PONS_SELL, TOPIC_PONS_COMPLETED } from '../chain/constants';
import { word, toUint, topicAddress } from '../chain/abi';
import type { RawLog } from '../chain/types';
import type { Pool, Trade } from './types';
import { execPrice, trade } from './common';

/** CurveBuy(address indexed buyer, address indexed recipient, uint256 quoteIn, uint256 tokensOut, uint256 fee, uint256 tax)
 *  CurveSell(address indexed seller, address indexed recipient, uint256 tokensIn, uint256 quoteOut, uint256 fee, uint256 tax) */
export function decodePonsCurve(log: RawLog, pool: Pool): Trade | null {
  if (log.topics.length < 3) return null;
  if (log.topics[0] === TOPIC_PONS_BUY) {
    const quote = toUint(word(log.data, 0)), tokens = toUint(word(log.data, 1));
    if (tokens === 0n) return null;
    return trade(log, pool, { buy: true, quoteIn: quote, tokensOut: tokens, priceQuotePerToken: execPrice(quote, tokens, pool.decimals), recipient: topicAddress(log.topics[2]) });
  }
  if (log.topics[0] === TOPIC_PONS_SELL) {
    const tokens = toUint(word(log.data, 0)), quote = toUint(word(log.data, 1));
    if (tokens === 0n) return null;
    return trade(log, pool, { buy: false, quoteIn: quote, tokensOut: tokens, priceQuotePerToken: execPrice(quote, tokens, pool.decimals), recipient: topicAddress(log.topics[2]) });
  }
  return null;
}

export function isPonsCompleted(log: RawLog): boolean {
  return log.topics[0] === TOPIC_PONS_COMPLETED;
}
```

```ts
const SCHEMA = `
CREATE TABLE IF NOT EXISTS tokens (
  address TEXT PRIMARY KEY,
  symbol TEXT NOT NULL,
  decimals INTEGER NOT NULL,
  total_supply TEXT NOT NULL,
  pons_curve TEXT,
  pons_phase INTEGER,

CREATE TABLE IF NOT EXISTS seen_logs (

CREATE INDEX IF NOT EXISTS seen_logs_at ON seen_logs(seen_at);
CREATE TABLE IF NOT EXISTS meta (
  key TEXT PRIMARY KEY,
  value TEXT NOT NULL

`;

const TOKEN_COLS = `address, symbol, decimals, total_supply AS totalSupply, pons_curve AS ponsCurve,
  pons_phase AS ponsPhase, created_at AS createdAt, last_refresh AS lastRefresh`;
const POOL_COLS = `id, token, kind, token_is_0 AS tokenIs0, quote, fee, decimals`;
const GT_COLS = `chat_id AS chatId, token, emoji, step_usd AS stepUsd, min_buy_usd AS minBuyUsd,
  media_file_id AS mediaFileId, media_type AS mediaType, added_by AS addedBy, active`;
/** Same columns qualified with the `gt.` alias, for the JOIN in groupsForToken. */
const GT_COLS_Q = `gt.chat_id AS chatId, gt.token, gt.emoji, gt.step_usd AS stepUsd, gt.min_buy_usd AS minBuyUsd,
  gt.media_file_id AS mediaFileId, gt.media_type AS mediaType, gt.added_by AS addedBy, gt.active`;

type RawToken = Omit<TokenRow, 'totalSupply'> & { totalSupply: string };
type RawPool = Omit<Pool, 'tokenIs0'> & { tokenIs0: number };
type RawGt = Omit<GroupTokenRow, 'active'> & { active: number };

const mapToken = (r: RawToken): TokenRow => ({ ...r, totalSupply: BigInt(r.totalSupply) });
const mapPool = (r: RawPool): Pool => ({ id: r.id, token: r.token, kind: r.kind as PoolKind, tokenIs0: !!r.tokenIs0, quote: r.quote, fee: r.fee, decimals: r.decimals });
const mapGt = (r: RawGt): GroupTokenRow => ({ ...r, active: !!r.active });

export class Db {
  private db: Database.Database;

  constructor(path: string) {
    if (path !== ':memory:') mkdirSync(dirname(path), { recursive: true });
    this.db = new Database(path);
    this.db.pragma('journal_mode = WAL');
    this.db.exec(SCHEMA);
    this.migrate();
  }

  /** Numbered migrations applied in order; v1 is the base schema above. */
  private migrate(): void {
    const current = Number(this.getMeta('schema_version') ?? '0');
    // future: if (current < 2) { this.db.exec('ALTER TABLE …'); }
    if (current < SCHEMA_VERSION) this.setMeta('schema_version', String(SCHEMA_VERSION));
  }

  // --- tokens ---------------------------------------------------------------------------

  upsertToken(t: Omit<TokenRow, 'createdAt' | 'lastRefresh'>, now: number): void {
    this.db.prepare(`INSERT INTO tokens (address, symbol, decimals, total_supply, pons_curve, pons_phase, created_at, last_refresh)
      VALUES (?, ?, ?, ?, ?, ?, ?, ?)
      ON CONFLICT(address) DO UPDATE SET symbol = excluded.symbol, decimals = excluded.decimals,
        total_supply = excluded.total_supply, pons_curve = excluded.pons_curve, pons_phase = excluded.pons_phase,
        last_refresh = excluded.last_refresh`)
      .run(t.address, t.symbol, t.decimals, t.totalSupply.toString(), t.ponsCurve, t.ponsPhase, now, now);
  }

  getToken(address: string): TokenRow | null {
    const r = this.db.prepare(`SELECT ${TOKEN_COLS} FROM tokens WHERE address = ?`).get(address) as RawToken | undefined;
    return r ? mapToken(r) : null;
```

```ts
import { log as defaultLog, type LogFn } from './logger';
import type { MediaType } from './db/index';

export function escapeHtml(s: string): string {
  return s.replace(/&/g, '&amp;').replace(/</g, '&lt;').replace(/>/g, '&gt;').replace(/"/g, '&quot;');
}

export type InlineButton =
  | { text: string; url: string }
  | { text: string; callback_data: string }
  | { text: string; copy_text: { text: string } };
export type Keyboard = InlineButton[][];

export interface Media { type: MediaType; fileId: string }

export interface SendPayload {
  text: string;
  buttons?: Keyboard;
  media?: Media;
  disablePreview?: boolean;
}

export interface SendResult {
  ok: boolean;
  messageId?: number;
  errorCode?: number;
  description?: string;
}

export interface TgUpdate {
  update_id: number;
  message?: any;
  callback_query?: any;
  my_chat_member?: any;
}

const MEDIA_METHOD: Record<MediaType, { method: string; field: string }> = {
  animation: { method: 'sendAnimation', field: 'animation' },
  video: { method: 'sendVideo', field: 'video' },
  photo: { method: 'sendPhoto', field: 'photo' },
};

/** Thin Bot API client. Every method is safe to call concurrently; none throws. */
export class Telegram {
  constructor(private botToken: string, private fetchFn: typeof fetch = fetch, private logFn: LogFn = defaultLog) {}

  async send(chatId: number, p: SendPayload): Promise<SendResult> {
    const markup = p.buttons?.length ? { reply_markup: { inline_keyboard: p.buttons } } : {};
    if (p.media) {
      const { method, field } = MEDIA_METHOD[p.media.type];
      return this.post(method, { chat_id: chatId, [field]: p.media.fileId, caption: p.text, parse_mode: 'HTML', ...markup });
    }
    return this.post('sendMessage', {
      chat_id: chatId, text: p.text, parse_mode: 'HTML',
      link_preview_options: { is_disabled: p.disablePreview !== false }, ...markup,
    });
  }

  async editText(chatId: number, messageId: number, text: string, buttons: Keyboard = []): Promise<boolean> {
    const markup = buttons.length ? { reply_markup: { inline_keyboard: buttons } } : { reply_markup: { inline_keyboard: [] } };
    const r = await this.post('editMessageText', { chat_id: chatId, message_id: messageId, text, parse_mode: 'HTML', link_preview_options: { is_disabled: true }, ...markup }, 1);
    return r.ok;
  }

  async deleteMessage(chatId: number, messageId: number): Promise<boolean> {
    return (await this.post('deleteMessage', { chat_id: chatId, message_id: messageId }, 1)).ok;
  }

  async answerCallbackQuery(id: string, text?: string): Promise<void> {
    await this.post('answerCallbackQuery', { callback_query_id: id, ...(text ? { text } : {}) }, 1);
  }

  /** Long-poll. 25 s server timeout; `[]` on any failure so the loop just polls again. */
  async getUpdates(offset: number): Promise<TgUpdate[]> {
    const j = await this.call('getUpdates', { offset, timeout: 25, allowed_updates: ['message', 'callback_query', 'my_chat_member'] }, 35_000);
    return Array.isArray(j?.result) ? j.result : [];
  }

  async getChatAdministrators(chatId: number): Promise<number[] | null> {
    const j = await this.call('getChatAdministrators', { chat_id: chatId }, 10_000);
    if (!Array.isArray(j?.result)) return null;
    return j.result.map((m: any) => Number(m?.user?.id)).filter((n: number) => Number.isFinite(n));
  }

  async getMe(): Promise<string | null> {
    const j = await this.call('getMe', {}, 10_000);
    return typeof j?.result?.username === 'string' ? j.result.username : null;
  }

  async setMyCommands(commands: Array<{ command: string; description: string }>): Promise<void> {
    await this.call('setMyCommands', { commands }, 10_000);
  }

  /** Single-attempt raw call returning the parsed body (ok or not), or null on transport failure. */
  private async call(method: string, body: object, timeoutMs: number): Promise<any | null> {
    try {
      const res = await this.fetchFn(`https://api.telegram.org/bot${this.botToken}/${method}`, {
        method: 'POST', headers: { 'content-type': 'application/json' },
        body: JSON.stringify(body), signal: AbortSignal.timeout(timeoutMs),
      });
      const j = await res.json().catch(() => null);
      return res.ok ? j : null;
    } catch {
      return null;
    }
  }

  /** Send with 429 handling. 4xx other than 429 is returned immediately with its code/description. */
  private async post(method: string, body: object, attempts = 3): Promise<SendResult> {
    let last: SendResult = { ok: false };
    for (let attempt = 0; attempt < attempts; attempt++) {
      try {
        const res = await this.fetchFn(`https://api.telegram.org/bot${this.botToken}/${method}`, {
          method: 'POST', headers: { 'content-type': 'application/json' },
          body: JSON.stringify(body), signal: AbortSignal.timeout(10_000),
        });
        const j = (await res.json().catch(() => null)) as any;
        if (res.ok) return { ok: true, messageId: j?.result?.message_id };
        const description: string = j?.description ?? '';
        if (res.status === 429) {
          const wait = ((j?.parameters?.retry_after ?? 3) + 1) * 1000;
          last = { ok: false, errorCode: 429, description };
          if (attempt < attempts - 1) await new Promise((r) => setTimeout(r, wait));
          continue;
        }
        if (res.status === 400 && description.includes('message is not modified')) return { ok: true };
        return { ok: false, errorCode: res.status, description };
      } catch (e) {
        last = { ok: false, description: (e as Error).message };
        this.logFn('warn', `telegram ${method} attempt ${attempt + 1} failed: ${(e as Error).message}`);
      }
    }
    return last;
  }
}
```

```ts
import { encodeCall, decodeResult, decodeAbiString, toAddress, word, toUint } from './chain/abi';
import { SEL, WETH, NATIVE, UNI_V2_FACTORY, UNI_V3_FACTORY, UNI_V3_FEES, UNI_V4_STATE_VIEW, PONS_V2_FACTORY, PONS_LAUNCH_TUPLE, GECKO_API, GECKO_V4_DEX_IDS } from './chain/constants';
import type { Pool } from './decoders/types';
import { log as defaultLog, type LogFn } from './logger';

export class DiscoveryError extends Error {
  constructor(public kind: 'not_erc20' | 'no_pools' | 'rpc', msg: string) {
    super(msg);
    this.name = 'DiscoveryError';
  }
}

export interface DiscoveredPools {
  pools: Pool[];
  ponsCurve: string | null;
  ponsPhase: number | null;
  ponsProgressPct: number | null;
}

export interface DiscoveredToken extends DiscoveredPools {
  address: string;
  symbol: string;
  decimals: number;
  totalSupply: bigint;

export function venueLabel(pool: Pool, ponsProgressPct: number | null): string {
  switch (pool.kind) {
    case 'pons_curve': return ponsProgressPct === null ? 'Pons curve' : `Pons curve (${Math.round(ponsProgressPct)}% to graduation)`;
    case 'v2': return 'Uni V2';
    case 'v3': return `Uni V3 ${(pool.fee ?? 0) / 10000}%`;
    case 'v4': return 'Uni V4';
  }
}

export class Discovery {
  constructor(private rpc: Rpc, private fetchFn: typeof fetch = fetch, private logFn: LogFn = defaultLog, private maxV4Pools = 25) {}

  async discover(address: string): Promise<DiscoveredToken> {
    const token = address.toLowerCase();
    let meta;
    try {
      meta = await this.rpc.batchSettled([
        { method: 'eth_call', params: [{ to: token, data: SEL.symbol }, 'latest'] },
        { method: 'eth_call', params: [{ to: token, data: SEL.decimals }, 'latest'] },
        { method: 'eth_call', params: [{ to: token, data: SEL.totalSupply }, 'latest'] },
      ]);
    } catch (e) {
      throw new DiscoveryError('rpc', (e as Error).message);
    }
    const [sym, dec, sup] = meta;
    if (!dec.ok || !sup.ok || typeof dec.result !== 'string' || dec.result === '0x' || typeof sup.result !== 'string' || sup.result === '0x') {
      throw new DiscoveryError('not_erc20', 'address is not an ERC-20 token');
    }
    const symbol = (sym.ok && decodeAbiString(sym.result as string)) || '???';
    const decimals = Number(toUint(word(dec.result, 0)));
    const totalSupply = toUint(word(sup.result, 0));
    const pools = await this.discoverPools(token, decimals);
    if (!pools.pools.length) throw new DiscoveryError('no_pools', 'no ETH-quoted pool found on Pons or Uniswap');
    return { address: token, symbol, decimals, totalSupply, ...pools };
  }

  async discoverPools(address: string, decimals: number): Promise<DiscoveredPools> {
    const token = address.toLowerCase();
    const pools: Pool[] = [];
    let ponsCurve: string | null = null, ponsPhase: number | null = null, ponsProgressPct: number | null = null;

    let first;
    try {
      first = await this.rpc.batchSettled([
        { method: 'eth_call', params: [{ to: PONS_V2_FACTORY, data: encodeCall(SEL.getLaunchedToken, ['address'], [token]) }, 'latest'] },
        { method: 'eth_call', params: [{ to: UNI_V2_FACTORY, data: encodeCall(SEL.getPair, ['address', 'address'], [token, WETH]) }, 'latest'] },
        ...UNI_V3_FEES.map((fee) => ({ method: 'eth_call', params: [{ to: UNI_V3_FACTORY, data: encodeCall(SEL.getPool, ['address', 'address', 'uint24'], [token, WETH, fee]) }, 'latest'] })),
      ]);
    } catch (e) {
      throw new DiscoveryError('rpc', (e as Error).message);
    }

    // Pons V2
    const pons = first[0];
    if (pons.ok && typeof pons.result === 'string' && pons.result.length > 66) {
      const [t] = decodeResult([PONS_LAUNCH_TUPLE], pons.result) as any[];
      if (t.exists) {
        ponsCurve = String(t.curve).toLowerCase();
        ponsPhase = Number(t.phase);
        const pairToken = String(t.pairToken).toLowerCase();
        if (ponsPhase < 2 && pairToken === NATIVE) {
          pools.push({ id: ponsCurve, token, kind: 'pons_curve', tokenIs0: false, quote: NATIVE, fee: null, decimals });
          try {
            const [real, thr] = await this.rpc.batch([
              { method: 'eth_call', params: [{ to: ponsCurve, data: SEL.realQuoteReserve }, 'latest'] },
              { method: 'eth_call', params: [{ to: ponsCurve, data: SEL.graduationThreshold }, 'latest'] },
            ]) as string[];
            const t2 = toUint(word(thr, 0));
            if (t2 > 0n) ponsProgressPct = Math.min(100, Number(toUint(word(real, 0)) * 10000n / t2) / 100);
          } catch (e) {
            this.logFn('warn', `discovery: pons progress for ${token} failed: ${(e as Error).message}`);
          }
        }
      }
    }

    // V2 + V3 candidates → token0 lookups
    const candidates: Array<{ id: string; kind: 'v2' | 'v3'; fee: number | null }> = [];
    const pair = first[1];
    if (pair.ok && typeof pair.result === 'string' && !isZeroAddr(pair.result)) candidates.push({ id: toAddress(pair.result.slice(2)), kind: 'v2', fee: null });
    UNI_V3_FEES.forEach((fee, i) => {
      const r = first[2 + i];
      if (r.ok && typeof r.result === 'string' && !isZeroAddr(r.result)) candidates.push({ id: toAddress(r.result.slice(2)), kind: 'v3', fee });
    });
    if (candidates.length) {
      const t0s = await this.rpc.batchSettled(candidates.map((c) => ({ method: 'eth_call', params: [{ to: c.id, data: SEL.token0 }, 'latest'] })));
      candidates.forEach((c, i) => {
        const r = t0s[i];
        if (!r.ok || typeof r.result !== 'string' || r.result.length < 66) return;
        pools.push({ id: c.id, token, kind: c.kind, tokenIs0: toAddress(r.result.slice(2)) === token, quote: WETH, fee: c.fee, decimals });
      });
    }

    // V4 via GeckoTerminal, verified with StateView.getSlot0
    for (const p of await this.v4Candidates(token)) {
      pools.push({ ...p, decimals });
    }

    return { pools, ponsCurve, ponsPhase, ponsProgressPct };
  }

  private async v4Candidates(token: string): Promise<Array<Omit<Pool, 'decimals'>>> {
    let items: any[];
    try {
      const res = await this.fetchFn(`${GECKO_API}/tokens/${token}/pools?page=1`, { headers: { accept: 'application/json' }, signal: AbortSignal.timeout(10_000) });
      if (!res.ok) throw new Error(`http ${res.status}`);
      items = ((await res.json()) as any).data ?? [];
    } catch (e) {
      this.logFn('warn', `discovery: geckoterminal pools for ${token} failed: ${(e as Error).message}`);
      return [];
    }
    const out: Array<Omit<Pool, 'decimals'>> = [];
    for (const it of items) {
      const dex = it?.relationships?.dex?.data?.id;
      if (!GECKO_V4_DEX_IDS.has(dex)) continue;
      const base = String(it.relationships?.base_token?.data?.id ?? '').replace('robinhood_', '').toLowerCase();
      const quote = String(it.relationships?.quote_token?.data?.id ?? '').replace('robinhood_', '').toLowerCase();
      const other = base === token ? quote : quote === token ? base : null;
      if (other !== NATIVE && other !== WETH) continue;
      const id = String(it.attributes?.address ?? '').toLowerCase();
      if (!/^0x[0-9a-f]{64}$/.test(id)) continue;
      const m = /(\d+(?:\.\d+)?)%\s*$/.exec(String(it.attributes?.name ?? ''));
      const fee = m ? Math.round(parseFloat(m[1]) * 10000) : 0;
      out.push({ id, token, kind: 'v4', tokenIs0: other === NATIVE ? false : token < other, quote: other, fee });
      if (out.length >= this.maxV4Pools) break;
    }
    if (!out.length) return [];
    try {
      const slots = await this.rpc.batchSettled(out.map((p) => ({ method: 'eth_call', params: [{ to: UNI_V4_STATE_VIEW, data: SEL.getSlot0 + p.id.slice(2) }, 'latest'] })));
      return out.filter((_, i) => { const r = slots[i]; return r.ok && typeof r.result === 'string' && r.result.length >= 66 && toUint(word(r.result, 0)) > 0n; });
    } catch (e) {
      this.logFn('warn', `discovery: getSlot0 batch for ${token} failed: ${(e as Error).message}`);
      return out;
    }
  }
}
```

```ts
import type { Rpc } from './chain/rpc';
import { SEL, ETH_USD_POOL } from './chain/constants';
import { encodeCall, word, toUint } from './chain/abi';
import type { Trade } from './decoders/types';
import type { TokenRow } from './db/index';
import { log as defaultLog, type LogFn } from './logger';

/** USDG/WETH V3 pool: token0 = WETH (18), token1 = USDG (6). price1per0 × 1e12 = USD per ETH. */
export function sqrtToEthUsd(sqrtPriceX96: bigint): number {
  const r = Number(sqrtPriceX96) / 2 ** 96;
  return r * r * 1e12;
}

export class EthUsdOracle {
  private cached: { value: number; at: number } | null = null;

  constructor(private rpc: Pick<Rpc, 'call'>, private ttlMs = 30_000) {}

  async get(now: number): Promise<number | null> {
    if (this.cached && now - this.cached.at < this.ttlMs) return this.cached.value;
    try {
      const hex = await this.rpc.call(ETH_USD_POOL, SEL.slot0);
      const v = sqrtToEthUsd(toUint(word(hex, 0)));
      if (v > 0 && Number.isFinite(v)) this.cached = { value: v, at: now };
    } catch {
      // keep the last good value
    }
    return this.cached?.value ?? null;
  }
}

export interface EnrichedBuy extends Trade {
  /** Resolved wallet (tx.from), falling back to the event recipient. */
  buyer: string;
  ethUsd: number | null;
  usd: number | null;
  marketCapUsd: number | null;
  holder: { isNew: boolean; positionIncreasePct: number | null } | null;
  /** Only for buys on a Pons curve. */
  ponsProgressPct: number | null;
}

export interface EnrichDeps {
  rpc: Pick<Rpc, 'call' | 'batch' | 'getTransactionFrom'>;
  oracle: EthUsdOracle;
  logFn?: LogFn;
}

export async function enrich(trade: Trade, token: TokenRow, deps: EnrichDeps, now: number): Promise<EnrichedBuy> {
  const logFn = deps.logFn ?? defaultLog;
  const isPons = trade.pool.kind === 'pons_curve';

  const [ethUsdR, fromR, ponsR] = await Promise.allSettled([
    deps.oracle.get(now),
    deps.rpc.getTransactionFrom(trade.txHash),
    isPons
      ? deps.rpc.batch([
          { method: 'eth_call', params: [{ to: trade.pool.id, data: SEL.getReserves }, 'latest'] },
          { method: 'eth_call', params: [{ to: trade.pool.id, data: SEL.realQuoteReserve }, 'latest'] },
          { method: 'eth_call', params: [{ to: trade.pool.id, data: SEL.graduationThreshold }, 'latest'] },
        ])
      : Promise.resolve(null),
  ]);

  const ethUsd = ethUsdR.status === 'fulfilled' ? ethUsdR.value : null;
  const buyer = fromR.status === 'fulfilled' && fromR.value ? fromR.value : trade.recipient;
  if (fromR.status === 'rejected') logFn('warn', `enrich: tx.from for ${trade.txHash} failed: ${String(fromR.reason)}`);

  let price = trade.priceQuotePerToken;
  let ponsProgressPct: number | null = null;
  if (isPons) {
    if (ponsR.status === 'fulfilled' && ponsR.value) {
      const [reserves, real, thr] = ponsR.value as string[];
      const q = toUint(word(reserves, 0)), t = toUint(word(reserves, 1));
      if (t > 0n) price = (Number(q) / Number(t)) * 10 ** token.decimals / 1e18;
      const thrN = toUint(word(thr, 0));
      if (thrN > 0n) ponsProgressPct = Math.min(100, Number((toUint(word(real, 0)) * 10000n) / thrN) / 100);
    } else if (ponsR.status === 'rejected') {
      logFn('warn', `enrich: pons reserves for ${trade.pool.id} failed: ${String(ponsR.reason)}`);
    }
  }

  const usd = ethUsd === null ? null : (Number(trade.quoteIn) / 1e18) * ethUsd;
  const supply = Number(token.totalSupply) / 10 ** token.decimals;
  const marketCapUsd = ethUsd === null || !(price > 0) ? null : supply * price * ethUsd;

  let holder: EnrichedBuy['holder'] = null;
  try {
    const hex = await deps.rpc.call(trade.token, encodeCall(SEL.balanceOf, ['address'], [buyer]), trade.blockNumber - 1);
    const before = toUint(word(hex, 0));
    holder = before === 0n
      ? { isNew: true, positionIncreasePct: null }
      : { isNew: false, positionIncreasePct: Number((trade.tokensOut * 10000n) / before) / 100 };
  } catch (e) {
    logFn('warn', `enrich: balanceOf(${buyer}) at ${trade.blockNumber - 1} failed: ${(e as Error).message}`);
  }

  return { ...trade, buyer, ethUsd, usd, marketCapUsd, holder, ponsProgressPct };
}
```

```ts
import type { Telegram, SendPayload, SendResult } from './telegram';
import type { Db } from './db/index';
import { log as defaultLog, type LogFn } from './logger';

export interface PosterOpts {
  perChatIntervalMs: number;
  globalPerSec: number;
  maxPendingPerChat: number;
  tickMs: number;
}

export const DEFAULT_POSTER_OPTS: PosterOpts = { perChatIntervalMs: 3000, globalPerSec: 25, maxPendingPerChat: 20, tickMs: 50 };

interface Job { chatId: number; token: string; payload: SendPayload }

const MEDIA_ERROR = /wrong file identifier|failed to get HTTP URL content|wrong type of the web page content|file is too big|WEBPAGE_MEDIA_EMPTY|MEDIA_EMPTY/i;
const GONE_ERROR = /chat not found|group chat was upgraded|bot was kicked|bot is not a member|CHAT_WRITE_FORBIDDEN|have no rights to send/i;

/** Per-chat + global rate-limited send queue. One queue per chat; a chat never has two sends in flight. */
export class Poster {
  private queues = new Map<number, Job[]>();
  private lastSent = new Map<number, number>();
  private dropped = new Map<number, number>();
  private inFlight = new Set<number>();
  private sentAt: number[] = [];
  private timer: NodeJS.Timeout | null = null;

  constructor(
    private tg: Pick<Telegram, 'send'>,
    private db: Pick<Db, 'setGroupActive' | 'updateGroupToken'>,
    private opts: PosterOpts = DEFAULT_POSTER_OPTS,
    private logFn: LogFn = defaultLog,
  ) {}

  enqueue(chatId: number, token: string, payload: SendPayload): void {
    let q = this.queues.get(chatId);
    if (!q) { q = []; this.queues.set(chatId, q); }
    if (q.length >= this.opts.maxPendingPerChat) {
      q.shift();
      this.dropped.set(chatId, (this.dropped.get(chatId) ?? 0) + 1);
    }
    q.push({ chatId, token, payload });
  }

  pending(chatId: number): number {
    return this.queues.get(chatId)?.length ?? 0;
  }

  start(): void {
    if (this.timer) return;
    this.timer = setInterval(() => void this.tick(Date.now()), this.opts.tickMs);
    this.timer.unref?.();
  }

  stop(): void {
    if (this.timer) { clearInterval(this.timer); this.timer = null; }
  }

  /** One scheduler pass at `now`. Sends at most `globalPerSec` per rolling second, one per chat per interval. */
  async tick(now: number): Promise<void> {
    this.sentAt = this.sentAt.filter((t) => now - t < 1000);
    const sends: Promise<void>[] = [];
    for (const [chatId, q] of this.queues) {
      if (!q.length || this.inFlight.has(chatId)) continue;
      if (this.sentAt.length >= this.opts.globalPerSec) break;
      const last = this.lastSent.get(chatId);
      if (last !== undefined && now - last < this.opts.perChatIntervalMs) continue;
      const job = q.shift()!;
      this.lastSent.set(chatId, now);
      this.sentAt.push(now);
      this.inFlight.add(chatId);
      sends.push(this.deliver(job).finally(() => this.inFlight.delete(chatId)));
    }
    await Promise.all(sends);
  }

  private async deliver(job: Job): Promise<void> {
    const n = this.dropped.get(job.chatId) ?? 0;
    if (n) this.dropped.delete(job.chatId);
    const text = n ? `${job.payload.text}\n⚡ ${n} more buy${n === 1 ? '' : 's'}` : job.payload.text;

    let res: SendResult = await this.tg.send(job.chatId, { ...job.payload, text });

    if (!res.ok && res.errorCode === 400 && job.payload.media && MEDIA_ERROR.test(res.description ?? '')) {
      this.logFn('warn', `poster: media rejected for chat ${job.chatId} / ${job.token} — clearing media (${res.description})`);
      this.db.updateGroupToken(job.chatId, job.token, { mediaFileId: null, mediaType: null });
      res = await this.tg.send(job.chatId, { ...job.payload, text, media: undefined });
    }

    if (!res.ok && (res.errorCode === 403 || (res.errorCode === 400 && GONE_ERROR.test(res.description ?? '')))) {
      this.logFn('warn', `poster: chat ${job.chatId} unreachable (${res.errorCode} ${res.description}) — deactivating group`);
      this.db.setGroupActive(job.chatId, false);
      this.queues.delete(job.chatId);
      return;
    }

    if (!res.ok) this.logFn('warn', `poster: send to ${job.chatId} failed: ${res.errorCode ?? ''} ${res.description ?? ''}`);
  }
}
```

```ts
import WebSocket from 'ws';
import { EventEmitter } from 'node:events';
import type { SubscriptionFilter } from './types';
import { normalizeLog } from './rpc';
import { log as defaultLog, type LogFn } from '../logger';

export interface SocketLike {
  on(event: string, fn: (...args: any[]) => void): void;
  send(data: string): void;
  close(): void;
  terminate(): void;
  readyState: number;
}

export interface WsOpts {
  staleMs?: number;
  watchdogMs?: number;
  makeSocket?: (url: string) => SocketLike;
  logFn?: LogFn;
  maxBackoffMs?: number;
}

type SubKind = 'heads' | 'logs';

/**
 * eth_subscribe client over a raw WebSocket. Emits:
 *  'open' — connected and subscriptions sent (the watcher backfills here)
 *  'close' — socket closed (a reconnect is scheduled unless close() was called)
 *  'head' (blockNumber) — newHeads
 *  'log' (RawLog) — a matching log
 *  'stale' — no message for staleMs; the socket is terminated and will reconnect
 */
export class WsClient extends EventEmitter {
  private ws: SocketLike | null = null;
  private closed = false;
  private backoffMs = 1000;
  private lastMessageAt = 0;
  private watchdog: NodeJS.Timeout | null = null;
  private reqId = 1;
  private filters: SubscriptionFilter[] = [];
  private pending = new Map<number, SubKind>();
  private subs = new Map<string, SubKind>();
  private opts: Required<WsOpts>;

  constructor(private url: string, opts: WsOpts = {}) {
    super();
    this.opts = {
      staleMs: 30_000, watchdogMs: 5_000, maxBackoffMs: 30_000, logFn: defaultLog,
      makeSocket: (u) => new WebSocket(u) as unknown as SocketLike,
      ...opts,
    };
  }

  connect(): void {
    if (this.closed) return;
    const ws = this.opts.makeSocket(this.url);
    this.ws = ws;
    ws.on('open', () => {
      this.backoffMs = 1000;
      this.lastMessageAt = Date.now();
      this.subscribeAll();
      this.emit('open');
    });
    ws.on('message', (data: unknown) => {
      this.lastMessageAt = Date.now();
      this.handleMessage(String(data));
    });
    ws.on('error', (err: Error) => this.opts.logFn('warn', `ws error: ${err.message}`));
    ws.on('close', () => {
      if (this.ws !== ws) return;
      this.ws = null;
      this.subs.clear();
      this.pending.clear();
      this.emit('close');
      if (this.closed) return;
      this.opts.logFn('warn', `ws closed — reconnecting in ${this.backoffMs}ms`);
      setTimeout(() => this.connect(), this.backoffMs);
      this.backoffMs = Math.min(this.backoffMs * 2, this.opts.maxBackoffMs);
    });
    this.ensureWatchdog();
  }

  isOpen(): boolean {
    return this.ws?.readyState === 1;
  }

  setSubscriptions(filters: SubscriptionFilter[]): void {
    this.filters = filters;
    if (this.isOpen()) {
      this.unsubscribeLogs();
      this.subscribeLogs();
    }
  }

  close(): void {
    this.closed = true;
    if (this.watchdog) { clearInterval(this.watchdog); this.watchdog = null; }
    this.ws?.close();
  }

  /** Terminate the socket if nothing arrived for staleMs (100 ms blocks mean newHeads should be constant). */
  checkStale(now: number): void {
    if (this.ws && this.lastMessageAt && now - this.lastMessageAt > this.opts.staleMs) {
      this.opts.logFn('warn', `ws: no messages for ${now - this.lastMessageAt}ms — terminating stale socket`);
      this.emit('stale');
      this.ws.terminate();
    }
  }

  private ensureWatchdog(): void {
    if (this.watchdog) return;
    this.watchdog = setInterval(() => this.checkStale(Date.now()), this.opts.watchdogMs);
    this.watchdog.unref?.();
  }

  private send(payload: object): void {
    if (this.isOpen()) this.ws!.send(JSON.stringify(payload));
  }

  private subscribeAll(): void {
    const id = this.reqId++;
    this.pending.set(id, 'heads');
    this.send({ jsonrpc: '2.0', id, method: 'eth_subscribe', params: ['newHeads'] });
    this.subscribeLogs();
  }

  private subscribeLogs(): void {
    for (const f of this.filters) {
      const id = this.reqId++;
      this.pending.set(id, 'logs');
      const param: Record<string, unknown> = { topics: f.topics };
      if (f.address?.length) param.address = f.address;
      this.send({ jsonrpc: '2.0', id, method: 'eth_subscribe', params: ['logs', param] });
    }
  }

  private unsubscribeLogs(): void {
    for (const [subId, kind] of [...this.subs]) {
      if (kind !== 'logs') continue;
      this.send({ jsonrpc: '2.0', id: this.reqId++, method: 'eth_unsubscribe', params: [subId] });
      this.subs.delete(subId);
    }
    for (const [id, kind] of [...this.pending]) if (kind === 'logs') this.pending.delete(id);
  }

  private handleMessage(raw: string): void {
    let msg: any;
    try { msg = JSON.parse(raw); } catch { return; }

    if (msg.id !== undefined && this.pending.has(msg.id)) {
      const kind = this.pending.get(msg.id)!;
      this.pending.delete(msg.id);
      if (typeof msg.result === 'string') this.subs.set(msg.result, kind);
      else this.opts.logFn('warn', `ws: subscribe (${kind}) failed: ${JSON.stringify(msg.error ?? msg)}`);
      return;
    }

    if (msg.method === 'eth_subscription') {
      const kind = this.subs.get(msg.params?.subscription);
      const r = msg.params?.result;
      if (!kind || !r) return;
      if (kind === 'heads') {
        const n = parseInt(r.number, 16);
        if (Number.isFinite(n)) this.emit('head', n);
      } else {
        try { this.emit('log', normalizeLog(r)); }
        catch (e) { this.opts.logFn('warn', `ws: bad log payload: ${(e as Error).message}`); }
      }
    }
  }
}
```

```ts
import type { Rpc } from './rpc';
import type { WsClient } from './ws';
import type { RawLog, SubscriptionFilter } from './types';
import type { Db } from '../db/index';
import type { Pool } from '../decoders/types';
import { TOPIC_V2_SWAP, TOPIC_V3_SWAP, TOPIC_V4_SWAP, TOPIC_PONS_BUY, TOPIC_PONS_COMPLETED, UNI_V4_POOL_MANAGER } from './constants';
import { log as defaultLog, type LogFn } from '../logger';

export interface WatcherOpts {
  backfillBlocks: number;
  pollFallbackAfterMs: number;
  pollIntervalMs: number;
  chunk: number;
  /** Blocks below the latest head the cursor is allowed to advance to on newHeads (logs for the newest blocks may still be in flight). */
  headMargin: number;
  nowFn?: () => number;
}

/** One address-filtered subscription for v2/v3/pons pools, one PoolId-filtered subscription on the V4 PoolManager. */
export function buildFilters(pools: Pool[]): SubscriptionFilter[] {
  const addrs = pools.filter((p) => p.kind !== 'v4').map((p) => p.id);
  const poolIds = pools.filter((p) => p.kind === 'v4').map((p) => p.id);
  const out: SubscriptionFilter[] = [];
  if (addrs.length) out.push({ address: addrs, topics: [[TOPIC_V2_SWAP, TOPIC_V3_SWAP, TOPIC_PONS_BUY, TOPIC_PONS_COMPLETED]] });
  if (poolIds.length) out.push({ address: [UNI_V4_POOL_MANAGER], topics: [TOPIC_V4_SWAP, poolIds] });
  return out;
}

export class Watcher {
  private filters: SubscriptionFilter[] = [];
  private cursor = 0;
  private backfilling = false;
  private fallbackTimer: NodeJS.Timeout | null = null;
  private pollTimer: NodeJS.Timeout | null = null;
  private stopped = false;
  private nowFn: () => number;

  constructor(
    private rpc: Pick<Rpc, 'blockNumber' | 'getLogs'>,
    private ws: WsClient,
    private db: Pick<Db, 'getCursor' | 'setCursor' | 'markSeen'>,
    private opts: WatcherOpts,
    private onLog: (log: RawLog) => Promise<void>,
    private logFn: LogFn = defaultLog,
  ) {
    this.nowFn = opts.nowFn ?? Date.now;
  }

  get cursorBlock(): number { return this.cursor; }
  get polling(): boolean { return this.pollTimer !== null; }

  setPools(pools: Pool[]): void {
    this.filters = buildFilters(pools);
    this.ws.setSubscriptions(this.filters);
  }

  async start(): Promise<void> {
    const saved = this.db.getCursor();
    this.cursor = saved ?? (await this.rpc.blockNumber());
    if (saved === null) this.db.setCursor(this.cursor);
    this.ws.on('open', () => { this.clearFallback(); this.stopPoll(); void this.backfill(); });
    this.ws.on('close', () => {
      this.clearFallback();
      this.fallbackTimer = setTimeout(() => this.startPoll(), this.opts.pollFallbackAfterMs);
    });
    this.ws.on('log', (l: RawLog) => void this.handle(l));
    this.ws.on('head', (n: number) => this.onHead(n));
    this.ws.connect();
  }

  stop(): void {
    this.stopped = true;
    this.clearFallback();
    this.stopPoll();
  }

  onHead(n: number): void {
    const c = n - this.opts.headMargin;
    if (c > this.cursor) this.setCursor(c);
  }

  /** Fetch [cursor+1, head] (bounded by backfillBlocks) in chunks through the same dispatch path. */
  async backfill(): Promise<number> {
    if (this.backfilling || !this.filters.length) return 0;
    this.backfilling = true;
    let count = 0;
    try {
      const head = await this.rpc.blockNumber();
      let from = Math.max(this.cursor + 1, head - this.opts.backfillBlocks);
      while (from <= head && !this.stopped) {
        const to = Math.min(from + this.opts.chunk - 1, head);
        const logs: RawLog[] = [];
        for (const f of this.filters) logs.push(...(await this.rpc.getLogs({ ...f, fromBlock: from, toBlock: to })));
        logs.sort((a, b) => a.blockNumber - b.blockNumber || a.logIndex - b.logIndex);
        for (const l of logs) { await this.handle(l); count++; }
        this.setCursor(to);
        from = to + 1;
      }
    } catch (e) {
      this.logFn('warn', `watcher: backfill failed: ${(e as Error).message}`);
    } finally {
      this.backfilling = false;
    }
    return count;
  }

  private async handle(log: RawLog): Promise<void> {
    if (log.removed) return;
    if (!this.db.markSeen(log.transactionHash, log.logIndex, this.nowFn())) return;
    try {
      await this.onLog(log);
    } catch (e) {
      this.logFn('error', `watcher: onLog failed for ${log.transactionHash}:${log.logIndex}: ${(e as Error).message}`);
    }
    if (log.blockNumber > this.cursor) this.setCursor(log.blockNumber);
  }

  private setCursor(n: number): void {
    this.cursor = n;
    this.db.setCursor(n);
  }

  private startPoll(): void {
    if (this.pollTimer || this.stopped) return;
    this.logFn('warn', 'watcher: WS down — polling eth_getLogs until it returns');
    this.pollTimer = setInterval(() => void this.backfill(), this.opts.pollIntervalMs);
  }

  private stopPoll(): void {
    if (!this.pollTimer) return;
    clearInterval(this.pollTimer);
    this.pollTimer = null;
    this.logFn('info', 'watcher: WS back — polling stopped');
  }

  private clearFallback(): void {
    if (this.fallbackTimer) { clearTimeout(this.fallbackTimer); this.fallbackTimer = null; }
  }
}
```

```ts
import { log as defaultLog, type LogFn } from '../logger';

export type PromptKind = 'emoji' | 'step' | 'minbuy' | 'media';
export interface Prompt { chatId: number; token: string; kind: PromptKind; menuMsgId: number; expiresAt: number }

export const STEP_CHOICES = [5, 10, 25, 50, 100];
export const MIN_CHOICES = [0, 10, 25, 50, 100];

const segmenter = new Intl.Segmenter('en', { granularity: 'grapheme' });

/** First grapheme of the text if it is an emoji, else null. */
export function parseEmoji(text: string): string | null {
  const first = [...segmenter.segment(text.trim())][0]?.segment;
  if (!first) return null;
  return /\p{Extended_Pictographic}/u.test(first) ? first : null;
}

const mediaLabel = (t: MediaType | null) => (t === 'animation' ? 'GIF' : t === 'video' ? 'video' : t === 'photo' ? 'photo' : 'none');

export function renderMenu(gt: GroupTokenRow, symbol: string): { text: string; buttons: Keyboard } {
  const t = gt.token;
  return {

      [{ text: '✖ Close', callback_data: 's:close' }],
    ],
  };

function extractMedia(m: any): { type: MediaType; fileId: string } | null {
  if (m.animation?.file_id) return { type: 'animation', fileId: m.animation.file_id };
  if (m.video?.file_id) return { type: 'video', fileId: m.video.file_id };
  if (Array.isArray(m.photo) && m.photo.length) return { type: 'photo', fileId: m.photo[m.photo.length - 1].file_id };
  const mime: string = m.document?.mime_type ?? '';
  if (m.document?.file_id && mime === 'image/gif') return { type: 'animation', fileId: m.document.file_id };
  if (m.document?.file_id && mime.startsWith('video/')) return { type: 'video', fileId: m.document.file_id };

export interface SettingsDeps {
  tg: Pick<Telegram, 'send' | 'editText' | 'answerCallbackQuery'>;
  db: Pick<Db, 'getGroupToken' | 'groupTokensForChat' | 'updateGroupToken' | 'getToken'>;
  logFn?: LogFn;
  promptTtlMs?: number;
}

export class Settings {
  private prompts = new Map<number, Prompt>(); // by admin user id
  private ttl: number;
  private logFn: LogFn;

  constructor(private deps: SettingsDeps) {
    this.ttl = deps.promptTtlMs ?? 5 * 60_000;
    this.logFn = deps.logFn ?? defaultLog;
  }

  pendingFor(userId: number, now: number): Prompt | null {
    const p = this.prompts.get(userId);
    if (!p) return null;
    if (p.expiresAt <= now) { this.prompts.delete(userId); return null; }
    return p;
  }

  /** /settings entry point (caller has verified admin rights). */
  async open(chatId: number, _userId: number, _now: number): Promise<void> {
    const tokens = this.deps.db.groupTokensForChat(chatId);
    if (!tokens.length) { await this.deps.tg.send(chatId, { text: T.settingsNone }); return; }
    if (tokens.length === 1) { await this.sendMenu(chatId, tokens[0]); return; }
    await this.deps.tg.send(chatId, { text: T.pickToken, buttons: tokens.map((gt) => [{ text: `$${this.symbol(gt.token)}`, callback_data: `s:menu:${gt.token}` }]) });
  }

  private symbol(token: string): string {
    return this.deps.db.getToken(token)?.symbol ?? token.slice(0, 8);
  }

  private async sendMenu(chatId: number, gt: GroupTokenRow): Promise<void> {
    const m = renderMenu(gt, this.symbol(gt.token));
    await this.deps.tg.send(chatId, m);
  }

  private async editMenu(chatId: number, messageId: number, token: string): Promise<void> {
    const gt = this.deps.db.getGroupToken(chatId, token);
    if (!gt) return;
    const m = renderMenu(gt, this.symbol(token));
    await this.deps.tg.editText(chatId, messageId, m.text, m.buttons);
  }

  private setPrompt(userId: number, p: Omit<Prompt, 'expiresAt'>, now: number): void {
    this.prompts.set(userId, { ...p, expiresAt: now + this.ttl });
  }

  /** Handle a callback query whose sender is an admin of cq.message.chat. Returns false if not a settings callback. */
  async onCallback(cq: any, now: number): Promise<boolean> {
    const data: string = cq.data ?? '';
    if (!data.startsWith('s:')) return false;
    const chatId: number = cq.message.chat.id;
    const messageId: number = cq.message.message_id;
    const userId: number = cq.from.id;
    const [, action, token, arg] = data.split(':');
    const back: Keyboard = [[{ text: '« Back', callback_data: `s:menu:${token}` }]];
    const ack = (text?: string) => this.deps.tg.answerCallbackQuery(cq.id, text);

    if (action === 'close') { this.prompts.delete(userId); await this.deps.tg.editText(chatId, messageId, T.closed, []); await ack(); return true; }
    if (!token || !this.deps.db.getGroupToken(chatId, token)) { await ack(T.notTracked); return true; }
    const symbol = this.symbol(token);

    switch (action) {
      case 'menu':
        this.prompts.delete(userId);
        await this.editMenu(chatId, messageId, token); break;
      case 'emoji':
        this.setPrompt(userId, { chatId, token, kind: 'emoji', menuMsgId: messageId }, now);
        await this.deps.tg.editText(chatId, messageId, T.promptEmoji(symbol), back); break;
      case 'step':

        ]); break;

        if (n >= MIN_RANGE[0] && n <= MIN_RANGE[1]) this.deps.db.updateGroupToken(chatId, token, { minBuyUsd: n });

    if (here !== p.chatId && !isDm) return false;

      const media = extractMedia(m);
      if (!media) { if (text.startsWith('/')) return false; await reply(T.mediaBad); return true; }

      await this.editMenu(p.chatId, p.menuMsgId, p.token);
      return true;
    }

      if (!emoji) { await reply(T.badEmoji); return true; }
      this.deps.db.updateGroupToken(p.chatId, p.token, { emoji });

      const n = Number(text.replace(/[$,\s]/g, ''));
      if (!Number.isFinite(n) || n < lo || n > hi) { await reply(T.badNumber(lo, hi)); return true; }
      this.deps.db.updateGroupToken(p.chatId, p.token, p.kind === 'step' ? { stepUsd: n } : { minBuyUsd: n });
    }
    this.prompts.delete(userId);
    await this.editMenu(p.chatId, p.menuMsgId, p.token);
    return true;
  }
```

```ts
import type { Db } from '../db/index';
import { DiscoveryError, venueLabel, type Discovery } from '../discovery';
import type { AppConfig } from '../types';

import { Settings } from './settings';
import { T } from './texts';
import { log as defaultLog, type LogFn } from '../logger';

export interface HandlerDeps {
  tg: TelegramApi;
  db: Db;
  discovery: Pick<Discovery, 'discover'>;
  cfg: AppConfig;
  settings: Settings;
  onPoolsChanged: () => void;
  botUsername: string;
  logFn?: LogFn;
  adminTtlMs?: number;

const ADDRESS_RE = /^0x[0-9a-fA-F]{40}$/;
const isGroup = (chat: any) => chat?.type === 'group' || chat?.type === 'supergroup';

export class CommandHandler {
  private adminCache = new Map<number, { ids: Set<number>; at: number }>();
  private offset = 0;
  private running = false;
  private logFn: LogFn;
  private adminTtl: number;

  constructor(private deps: HandlerDeps) {
    this.logFn = deps.logFn ?? defaultLog;
    this.adminTtl = deps.adminTtlMs ?? 5 * 60_000;
  }

  async run(): Promise<void> {
    this.running = true;
    while (this.running) {
      const updates = await this.deps.tg.getUpdates(this.offset);
      for (const u of updates) {
        this.offset = Math.max(this.offset, u.update_id + 1);
        try { await this.handleUpdate(u, Date.now()); }
        catch (e) { this.logFn('error', `handler: update ${u.update_id} failed: ${(e as Error).message}`); }
      }
      if (!updates.length) await new Promise((r) => setTimeout(r, 1000));
    }
  }

  stop(): void { this.running = false; }

  async isAdmin(chatId: number, userId: number, now: number): Promise<boolean> {
    if (userId === ANONYMOUS_ADMIN_ID) return true;
    const cached = this.adminCache.get(chatId);
    if (cached && now - cached.at < this.adminTtl) return cached.ids.has(userId);
    const ids = await this.deps.tg.getChatAdministrators(chatId);
    if (!ids) return cached?.ids.has(userId) ?? false;
    this.adminCache.set(chatId, { ids: new Set(ids), at: now });
    return ids.includes(userId);
  }

  async handleUpdate(u: TgUpdate, now: number): Promise<void> {
    if (u.my_chat_member) return this.onMembership(u.my_chat_member, now);
    if (u.callback_query) return this.onCallback(u.callback_query, now);
    if (u.message) return this.onMessage(u.message, now);
  }

  private async onMembership(mcm: any, now: number): Promise<void> {
    const chat = mcm.chat;
    const status: string = mcm.new_chat_member?.status ?? '';
    if (!isGroup(chat)) return;
    if (status === 'left' || status === 'kicked') {
      this.deps.db.setGroupActive(chat.id, false);
      this.deps.onPoolsChanged();
      this.logFn('info', `handler: removed from group ${chat.id} (${chat.title ?? ''})`);
      return;
    }
    if (status === 'member' || status === 'administrator') {
      const wasActive = this.deps.db.isGroupActive(chat.id);
      this.deps.db.upsertGroup(chat.id, chat.title ?? '', now);
      if (!wasActive) await this.deps.tg.send(chat.id, { text: T.welcome });
      this.deps.onPoolsChanged();
    }
  }

  private async onCallback(cq: any, now: number): Promise<void> {
    const chatId: number | undefined = cq.message?.chat?.id;
    const userId: number | undefined = cq.from?.id;
    if (chatId === undefined || userId === undefined) return;
    if (!(await this.isAdmin(chatId, userId, now))) { await this.deps.tg.answerCallbackQuery(cq.id, T.notAdmin); return; }
    if (!(await this.deps.settings.onCallback(cq, now))) await this.deps.tg.answerCallbackQuery(cq.id);
  }

  private async onMessage(m: any, now: number): Promise<void> {
    const chat = m.chat;
    const text: string = m.text ?? '';
    if (chat.type === 'private') {
      if (await this.deps.settings.onInput(m, now)) return;
      await this.deps.tg.send(chat.id, { text: T.help, buttons: [[{ text: T.addToGroup, url: `https://t.me/${this.deps.botUsername}?startgroup=true` }]] });
      return;
    }
    if (!isGroup(chat)) return;
    if (!text.startsWith('/')) { await this.deps.settings.onInput(m, now); return; }

    const [rawCmd, ...rest] = text.trim().split(/\s+/);
    const cmd = rawCmd.slice(1).split('@')[0].toLowerCase();
    const arg = rest[0];
    const userId: number = m.from?.id;
    if (!['add', 'remove', 'list', 'settings', 'start', 'help'].includes(cmd)) return;
    if (cmd === 'start' || cmd === 'help') { await this.deps.tg.send(chat.id, { text: T.help }); return; }
    if (!(await this.isAdmin(chat.id, userId, now))) { await this.deps.tg.send(chat.id, { text: T.notAdmin }); return; }
    this.deps.db.upsertGroup(chat.id, chat.title ?? '', now);

    switch (cmd) {
      case 'add': return this.add(chat.id, userId, arg, now);
      case 'remove': return this.remove(chat.id, arg);
      case 'list': return this.list(chat.id);
      case 'settings': return this.deps.settings.open(chat.id, userId, now);
    }
  }

  private async add(chatId: number, userId: number, arg: string | undefined, now: number): Promise<void> {
    const send = (text: string) => this.deps.tg.send(chatId, { text });
    if (!arg) { await send(T.addUsage); return; }
    if (!ADDRESS_RE.test(arg)) { await send(T.addBadAddress); return; }
    const address = arg.toLowerCase();
    const tracked = this.deps.db.groupTokensForChat(chatId);
    const existing = tracked.find((t) => t.token === address);
    if (existing) { await send(T.addAlready(escapeHtml(this.deps.db.getToken(address)?.symbol ?? address))); return; }
    if (tracked.length >= this.deps.cfg.limits.maxTokensPerGroup) { await send(T.addLimit(tracked.length)); return; }

    let d;
    try {
      d = await this.deps.discovery.discover(address);
    } catch (e) {
      const kind = e instanceof DiscoveryError ? e.kind : 'rpc';
      this.logFn('warn', `handler: /add ${address} in ${chatId} failed: ${kind} ${(e as Error).message}`);
      await send(kind === 'not_erc20' ? T.addNotErc20 : kind === 'no_pools' ? T.addNoPools : T.addRpc);
      return;
    }
    this.deps.db.upsertToken({ address: d.address, symbol: d.symbol, decimals: d.decimals, totalSupply: d.totalSupply, ponsCurve: d.ponsCurve, ponsPhase: d.ponsPhase }, now);
    for (const p of d.pools) this.deps.db.upsertPool(p);
    this.deps.db.addGroupToken(chatId, d.address, userId, this.deps.cfg.defaults, now);
    this.deps.onPoolsChanged();
    this.logFn('info', `handler: group ${chatId} added $${d.symbol} ${d.address} (${d.pools.length} pools)`);
    await send(T.added(escapeHtml(d.symbol), d.pools.map((p) => venueLabel(p, d.ponsProgressPct))));
  }

  private async remove(chatId: number, arg: string | undefined): Promise<void> {
    const send = (text: string) => this.deps.tg.send(chatId, { text });
    if (!arg) { await send(T.removeUsage); return; }
    const address = arg.toLowerCase();
    const gt = this.deps.db.getGroupToken(chatId, address);
    if (!gt || !gt.active) { await send(T.notTracked); return; }
    this.deps.db.removeGroupToken(chatId, address);
    this.deps.onPoolsChanged();
    await send(T.removed(escapeHtml(this.deps.db.getToken(address)?.symbol ?? address)));
  }

  private async list(chatId: number): Promise<void> {
    const rows = this.deps.db.groupTokensForChat(chatId);
    if (!rows.length) { await this.deps.tg.send(chatId, { text: T.listEmpty }); return; }
    const lines = rows.map((gt) => {
      const sym = escapeHtml(this.deps.db.getToken(gt.token)?.symbol ?? '?');
      return `• <b>$${sym}</b> <code>${gt.token}</code>\n  ${gt.emoji} $${gt.stepUsd}/emoji · min $${gt.minBuyUsd} · media: ${gt.mediaType ?? 'none'}`;
    });
    await this.deps.tg.send(chatId, { text: [T.listHeader, ...lines].join('\n') });
  }
}
```

```ts
/** Address → pool for v2/v3/pons; PoolId → pool for v4 logs (which all come from the PoolManager). */
export class PoolIndex {
  private byKey = new Map<string, Pool>();

  set(pools: Pool[]): void {
    this.byKey = new Map(pools.map((p) => [p.kind === 'v4' ? `v4:${p.id}` : p.id, p]));
  }

  lookup(log: RawLog): Pool | undefined {
    if (log.address === UNI_V4_POOL_MANAGER) return log.topics[1] ? this.byKey.get(`v4:${log.topics[1]}`) : undefined;
    return this.byKey.get(log.address);
  }

  get size(): number { return this.byKey.size; }
}

export interface PipelineDeps {
  db: Pick<Db, 'getToken' | 'groupsForToken' | 'setPonsPhase'>;
  poolIndex: PoolIndex;
  enrichDeps: EnrichDeps;
  cfg: CardConfig & Pick<AppConfig, 'limits'>;
  poster: Pick<Poster, 'enqueue'>;
  onPonsCompleted: (token: string) => void;
  logFn?: LogFn;
  nowFn?: () => number;
}

export function makeOnLog(deps: PipelineDeps): (log: RawLog) => Promise<void> {
  const logFn = deps.logFn ?? defaultLog;
  const nowFn = deps.nowFn ?? Date.now;
  return async (log) => {
    const pool = deps.poolIndex.lookup(log);
    if (!pool) return;
    if (pool.kind === 'pons_curve' && isPonsCompleted(log)) {
      deps.db.setPonsPhase(pool.token, 1);
      logFn('info', `pipeline: Pons curve completed for ${pool.token} — following graduation`);
      deps.onPonsCompleted(pool.token);
      return;
    }
    const trade = decodeTrade(log, pool);
    if (!trade || !trade.buy) return;
    const token = deps.db.getToken(pool.token);
    if (!token) return;
    const groups = deps.db.groupsForToken(pool.token);
    if (!groups.length) return;

    const buy = await enrich(trade, token, deps.enrichDeps, nowFn());
    let posted = 0;
    for (const g of groups) {
      if (buy.usd !== null && buy.usd < g.minBuyUsd) continue;
      const { text, buttons } = formatCard(buy, token, g, deps.cfg, deps.cfg.limits.maxEmojis);
      const media = g.mediaFileId && g.mediaType ? { type: g.mediaType, fileId: g.mediaFileId } : undefined;
      deps.poster.enqueue(g.chatId, token.address, { text, buttons, media });
      posted++;
    }
    logFn('info', `buy $${token.symbol} ${fmtEth(buy.quoteIn)}${buy.usd === null ? '' : ` (${fmtUsd(buy.usd)})`} via ${pool.kind} → ${posted}/${groups.length} group(s) tx ${buy.txHash}`);
  };
}
```

`src/refresh.ts`:
```ts
import type { Db } from './db/index';
import type { Discovery } from './discovery';
import { log as defaultLog, type LogFn } from './logger';

export interface RefresherDeps {
  db: Pick<Db, 'activeTokens' | 'getToken' | 'poolsForToken' | 'upsertPool' | 'deactivatePool' | 'setPonsPhase' | 'touchToken'>;
  discovery: Pick<Discovery, 'discoverPools'>;
  onPoolsChanged: () => void;
  intervalMs: number;
  graduationPollMs?: number;
  logFn?: LogFn;
  nowFn?: () => number;
}

/** Periodically re-discovers pools for every active token; follows a Pons graduation every few seconds until the V4 pool exists. */
export class Refresher {
  private timer: NodeJS.Timeout | null = null;
  private following = new Map<string, NodeJS.Timeout>();
  private logFn: LogFn;
  private nowFn: () => number;
  private gradMs: number;

  constructor(private deps: RefresherDeps) {
    this.logFn = deps.logFn ?? defaultLog;
    this.nowFn = deps.nowFn ?? Date.now;
    this.gradMs = deps.graduationPollMs ?? 30_000;
  }

  start(): void {
    if (this.timer) return;
    this.timer = setInterval(() => void this.refreshAll(), this.deps.intervalMs);
    this.timer.unref?.();
  }

  stop(): void {
    if (this.timer) { clearInterval(this.timer); this.timer = null; }
    for (const t of this.following.values()) clearInterval(t);
    this.following.clear();
  }

  async refreshAll(): Promise<void> {
    for (const t of this.deps.db.activeTokens()) await this.refreshToken(t.address);
  }

  /** Re-run pool discovery for one token. Returns true if the pool set or Pons phase changed. */
  async refreshToken(address: string): Promise<boolean> {
    const token = this.deps.db.getToken(address);
    if (!token) return false;
    let d;
    try {
      d = await this.deps.discovery.discoverPools(address, token.decimals);
    } catch (e) {
      this.logFn('warn', `refresh: ${address} failed: ${(e as Error).message}`);
      return false;
    }
    const before = new Set(this.deps.db.poolsForToken(address).map((p) => p.id));
    for (const p of d.pools) this.deps.db.upsertPool(p);
    let changed = d.pools.some((p) => !before.has(p.id));
    if (d.ponsCurve && d.ponsPhase === 2 && before.has(d.ponsCurve)) {
      this.deps.db.deactivatePool(d.ponsCurve);
      changed = true;
    }
    if (d.ponsPhase !== null && d.ponsPhase !== token.ponsPhase) {
      this.deps.db.setPonsPhase(address, d.ponsPhase);
      changed = true;
    }
    this.deps.db.touchToken(address, this.nowFn());
    if (changed) {
      this.logFn('info', `refresh: ${token.symbol} ${address} now has ${d.pools.length} pool(s), pons phase ${d.ponsPhase}`);
      this.deps.onPoolsChanged();
    }
    return changed;
  }

  followGraduation(token: string): void {
    if (this.following.has(token)) return;
    const t = setInterval(async () => {
      await this.refreshToken(token);
      if (this.deps.db.getToken(token)?.ponsPhase === 2) {
        clearInterval(t);
        this.following.delete(token);
        this.logFn('info', `refresh: ${token} graduated — curve retired, V4 pool live`);
      }
    }, this.gradMs);
    t.unref?.();
    this.following.set(token, t);
  }
}
```

```ts
import { loadConfig, loadSecrets } from './config';
import { log } from './logger';
import { Db } from './db/index';
import { Rpc } from './chain/rpc';
import { WsClient } from './chain/ws';
import { Watcher } from './chain/watcher';
import { Telegram, type TelegramApi } from './telegram';
import { DryTelegram } from './dryTelegram';
import { Discovery } from './discovery';
import { EthUsdOracle } from './enrich';
import { Poster } from './poster';
import { PoolIndex, makeOnLog } from './pipeline';
import { Refresher } from './refresh';
import { Settings } from './commands/settings';
import { CommandHandler } from './commands/handler';

const argv = process.argv.slice(2);
const dry = argv.includes('--dry');
const tokenFlag = argv.indexOf('--token');
const dryToken = tokenFlag >= 0 ? argv[tokenFlag + 1] : undefined;

async function main(): Promise<void> {
  const cfg = loadConfig();
  const secrets = loadSecrets();
  const db = new Db(secrets.dbPath);
  const rpc = new Rpc(secrets.rpcUrl);
  const tg: TelegramApi = dry ? new DryTelegram() : new Telegram(secrets.botToken);
  const botUsername = (await tg.getMe()) ?? 'bot';
  if (!dry) {
    await tg.setMyCommands([
      { command: 'add', description: 'Track a token: /add 0x…' },
      { command: 'settings', description: 'Emoji, step, min buy, GIF' },
      { command: 'list', description: 'Tracked tokens in this group' },
      { command: 'remove', description: 'Stop tracking: /remove 0x…' },
    ]);
  }

  const discovery = new Discovery(rpc);
  const oracle = new EthUsdOracle(rpc);
  const poster = new Poster(tg, db);
  const poolIndex = new PoolIndex();
  const ws = new WsClient(secrets.wsUrl, { staleMs: cfg.watcher.staleSeconds * 1000 });

  let watcher: Watcher; // assigned below; reloadPools only runs after it exists
  const reloadPools = () => {
    const pools = db.activePools();
    poolIndex.set(pools);
    watcher.setPools(pools);
    log('info', `watching ${pools.length} pool(s) for ${db.activeTokens().length} token(s)`);
  };
  const refresher = new Refresher({ db, discovery, onPoolsChanged: reloadPools, intervalMs: cfg.discovery.refreshMinutes * 60_000 });
  const onLog = makeOnLog({ db, poolIndex, enrichDeps: { rpc, oracle }, cfg, poster, onPonsCompleted: (t) => refresher.followGraduation(t) });
  watcher = new Watcher(rpc, ws, db, {
    backfillBlocks: cfg.watcher.backfillBlocks,
    pollFallbackAfterMs: cfg.watcher.pollFallbackAfterSeconds * 1000,
    pollIntervalMs: 2000, chunk: 10_000, headMargin: 2,
  }, onLog);

  if (dry && dryToken) {
    // Seed a fake group so a dry run has something to watch: `npm run dry -- --token 0x…`
    const d = await discovery.discover(dryToken);
    db.upsertGroup(-1, 'dry-run', Date.now());
    db.upsertToken({ address: d.address, symbol: d.symbol, decimals: d.decimals, totalSupply: d.totalSupply, ponsCurve: d.ponsCurve, ponsPhase: d.ponsPhase }, Date.now());
    for (const p of d.pools) db.upsertPool(p);
    db.addGroupToken(-1, d.address, 0, cfg.defaults, Date.now());
    log('info', `dry: tracking $${d.symbol} via ${d.pools.map((p) => p.kind).join(', ')}`);
  }

  reloadPools();
  poster.start();
  await watcher.start();
  refresher.start();

  const settings = new Settings({ tg, db });
  const handler = new CommandHandler({ tg, db, discovery, cfg, settings, onPoolsChanged: reloadPools, botUsername });
  if (!dry) void handler.run();

  const prune = setInterval(() => db.pruneSeen(Date.now() - 24 * 3600_000), 10 * 60_000);
  prune.unref?.();

  log('info', `robinhood-buybot started${dry ? ' (dry run — nothing is sent)' : ` as @${botUsername}`}`);

  const shutdown = () => {
    log('info', 'shutting down');
    handler.stop(); refresher.stop(); watcher.stop(); poster.stop(); ws.close(); clearInterval(prune);
    db.close();
    process.exit(0);
  };
  process.on('SIGINT', shutdown);
  process.on('SIGTERM', shutdown);
}

main().catch((e) => {
  log('error', `fatal: ${(e as Error).stack ?? String(e)}`);
  process.exit(1);
});
```

```
## How it works

One Node process. A `getUpdates` loop handles `/add`, `/settings`, `/list`, `/remove` and stores
per-group settings in SQLite. A `Watcher` keeps one WebSocket `eth_subscribe("logs")` filtered to
the tracked pools (address filter for V2/V3/Pons, PoolId filter on the V4 PoolManager), backfills
gaps with `eth_getLogs` and falls back to polling if the socket stays down. Pure decoders turn
each log into a normalised trade; the enricher adds ETH/USD (from the USDG/WETH pool), market cap,
the buyer wallet (`tx.from`) and New-Holder / Position +% (`balanceOf` at the previous block); the
rate-limited poster sends the card — with the group's uploaded GIF/video/photo — to every group
tracking that token. A Pons curve that graduates is followed automatically to its V4 pool.

Design: `docs/superpowers/specs/2026-08-25-buybot-design.md`. Research:
`docs/superpowers/research/2026-08-25-buybot-research.md`.
```
